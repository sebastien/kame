# Kame examples

- [`engine/`](engine/) contains Go programs that demonstrate the Kame reactive
  engine API.
- [`language/`](language/) contains runnable Kame build files (`.kmk`). Run an
  example from its project directory with `../../../build/kame.debug`, or build
  the CLI first with `make build/kame.debug` from the repository root.
- [`tutorial-blog/`](tutorial-blog/) is a Diátaxis tutorial that builds a
  minimalist personal blog (author page, posts, projects) from Markdown into
  plain HTML/CSS with pandoc. Its `README.md` is the lesson text.
